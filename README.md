# 楽天ポイント履歴 CSV ダウンロード
## 概要
楽天PointClubのポイント履歴をCSVファイルとしてダウンロードするブックマークレットです。

ポイント実績ページを開いた状態でブックマークレットを実行すると、表示されているポイント履歴の表をCSV形式で保存できます。

## 特徴
- ブラウザ上で動作します（環境構築は不要）
- ログイン情報（ユーザー名、パスワード）を要求しません

## 使い方
### 1. ブックマークレットを登録する
ブラウザで新規ブックマーク（お気に入り）を作成し、URLに以下のコードを貼り付けてください。
```
javascript:(function(url) { s = document.createElement("script"); s.src = url; document.body.appendChild(s); })('https://yuki-gu.github.io/ExportRakutenPointHistory/main.js');
```

### 2. ポイント履歴ページを開く
楽天PointClubの[ポイント実績](https://point.rakuten.co.jp/history/?l-id=point_top_history_pc)のページにアクセスします。

期間を指定したい場合は「さらに絞り込む」から期間を選択してください。

### 3. CSVファイルをダウンロードする
登録したブックマークをクリックすると、CSVファイルのダウンロードが始まります。

## CSVの各列の内容
- 日付: ポイント実績の「日付」列
- サービス: ポイント実績の「サービス」列（サービス名のみ）
- 内容: ポイント実績の「内容」列（内容、日付、ランクアップ対象）
- 詳細: ポイント実績の「内容」列に「詳細」ボタンがあった場合、その内容
- 動作: ポイント実績の「ポイント利用・獲得」列の種別（通常ポイント獲得、期間限定ポイント獲得、ポイント利用）
- ポイント: ポイント実績の「ポイント利用・獲得」列のポイント数（数値）
- 備考: ポイント実績の「備考」列

## 注意事項
- 楽天PointClubにログインした状態で実行してください。
- 楽天PointClubのページ構成が変更された場合、正常に動作しない可能性があります。
- Google Chromeにて動作確認を行っています。（2026/05/30）

## 技術詳細
- ポイント実績の表が複数ページにわたる場合、Fetch APIにより全ページの情報が取得されます。
- 次のページの取得は「NEXT」ボタンの押下によって行われます。
- CSV内の文字列は全てダブルクォートで囲まれます。（改行を含むため）
- CSVのエンコーディングはUTF-8（BOMあり）です。Excelでそのまま開けます。
- CSVファイルは\<a\>タグのクリックイベントにより自動ダウンロードされます。
